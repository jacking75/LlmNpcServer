# 게임서버 적합성 보고서 — 게임서버 대역 (Npc.TestGameServer)

회차: 테스트 회차 — 시각은 싣지 않는다

> 규약 전문은 `docs/reference_link.html` §11 이다. 이 보고서는 그 규약을
> **관찰로 확인한 결과**이고, 관찰하지 못한 항목은 미판정으로 적는다 —
> **미판정은 통과가 아니다.**

**판정: 합격** — 통과 6 · 불합격 0 · 미판정 1

## 회차

| 항목 | 값 |
|---|---|
| 협상 | protocol 2 · contract 1.3 · features 0x3E |
| NPC | 16 |
| 존 | 12 |
| 관찰 이벤트 | 311건 |
| 발행 명령 | 16건 |
| 마지막 틱 | 242 |
| 벽시계 | 구동 회차 (없음) |

## 판정

| 검사 | 판정 | 근거 |
|---|---|---|
| `C1.handshake` 핸드셰이크 · 재동기화 | **통과** | protocol 2 · contract minor 3 · features 0x3E · 스폰 16/16 · 존 12/12 · 프레임 최대 40건 |
| `C2.ticksync` TickSync — 단조 · 갭 0 · 10Hz | **통과** | TickSync 240건 · 틱 3~242 · 갭 0 · 속도 미판정 (구동 회차 — 벽시계가 없다) |
| `C3.sequence` 시퀀스 — 단조 · 갭 0 · 리셋 없음 | **통과** | 이벤트 311건 · 시퀀스 19~329 · 갭 0 · 되감김 0 |
| `C4.proximity` 근접 — 동시 1건 · 히스테리시스 · 에지 트리거 | **통과** | PlayerProximity 4건 (Enter 2 · Leave 2) · 관찰 끝에 열려 있는 NPC 0명 |
| `C5.combat` 전투 — DamageTaken 은 CombatStarted 뒤에만 | 미판정 | 전투 이벤트가 0건이다 — 이 회차에 전투가 없었다 |
| `C6.response` 명령 응답 — timeout_s 안에 · 상관 ID 일치 | **통과** | 명령 16건 · 응답 16건 (100.0 %) · 마감 초과 0 · 모르는 상관 ID 0 |
| `C7.throughput` 처리량 — 드롭 0 · 이벤트 백로그 없음 | **통과** | 명령 16건 · 드롭 0 · 프레임 241개 · 프레임당 평균 1.1건 · 최대 17건 |

## 미판정 — **지우지 않는다**

| 검사 | 왜 못 봤나 |
|---|---|
| `C5.combat` | 전투 이벤트가 0건이다 — 이 회차에 전투가 없었다 |

관찰 회차를 늘리거나 시나리오를 주입해야 판정할 수 있는 항목들이다.
