무의미해진다(`W1_env.md §4.3`). **상용 환경 외삽은 이 사실을 밝히고 한다** —
24GB 급에서는 동시성 상한이 달라지므로 아래 T1 항목은 그대로 옮기면 안 된다.

## 3. 프롬프트 캐시 절감액 — 실측

W11 골든 회차의 토큰 분해로 정확히 계산할 수 있다.

| 항목 | 계산 | 값 |
|---|---|---|
| 미적중 입력 | (3,012,661 − 1,223,508) × $0.10/M | $0.1789 |
| 적중 입력 | 1,223,508 × $0.01/M | $0.0122 |
| 출력 | 70,381 × $0.40/M | $0.0282 |
| **실제 비용** | | **$0.2193** |
| 캐시 없었다면 | 3,012,661 × $0.10/M + 출력 | $0.3294 |
| **절감액** | | **$0.1101 (33.4 %)** |

**적중률 40.6 % 로 비용의 33.4 % 를 줄였다.** 적중분이 1/10 단가라 적중률과
절감률이 거의 같은 비율로 움직인다.

> P3 게이트가 요구한 적중률은 95 % 였고 실측은 42.6 % 다. 이 차이는 엔진 특성이다 —
> Gemini 의 **암시적** 캐싱은 어느 요청이 적중할지 비결정적이고, `cached_tokens` 가
> 프리픽스 크기의 정수배로만 나온다(요청 단위 전부 적중 또는 전부 미적중,
> `W8_prebake.md §2`). 95 % 는 **명시적 캐싱**을 전제한 목표치다.

## 4. 런타임 비용 — **측정하지 않았다**

| 항목 | 값 |
|---|---|
| 시나리오 A 7게임일 런타임 LLM 비용 | **$0.00 (호출 0회)** |
| 월 환산 | 산출 불가 |

이 빌드의 런타임은 LLM 을 한 번도 부르지 않는다. 재계획 워커(T4-10·T4-11)가 아직
없어서 `Npc.Runtime` 에서 나가는 요청 자체가 없다 — P1 게이트가 확인한
"LLM 호출 카운터 = 0" 이 P5 까지 그대로다.

**따라서 §2 의 시나리오 B·C 는 실측이 아니라 "실측 단가 × 계획의 요청 수" 다.**
요청 수가 계획대로일지는 P4 의 인지 스케줄러가 붙어야 안다. 지금 아는 것은
**요청 하나의 단가**뿐이고, 그 단가는 실측이다.

## 5. T1 전력 비용 — 모델이지 실측이 아니다

GPU 사용률을 로깅한 회차가 없다. 아래는 **명시한 입력으로 세운 모델**이다.

| 입력 | 값 | 근거 |
|---|---|---|
| RTX 4060 TDP | 115 W | 제조사 공개값 |
| 8B 요청 지연 | 5.1 s | `W1_perf.csv` |
| 전기요금 | 150 원/kWh | 주택용 저압 대략치 |

| 산출 | 값 |
|---|---|
| 요청당 GPU 시간 | 5.1 s (동시 1 기준) |
| 요청당 전력량 | 115 W × 5.1 s = 0.000163 kWh |
| 요청당 전기요금 | **약 0.024 원** |
| 20,000건/일 전기요금 | 약 490 원/일 · **14,700 원/월** |

**그런데 이 기기로는 20,000건/일이 나오지 않는다.** 동시 1 에서 5.1s 면 하루 최대
16,944건이고, 동시성을 올리면 8B 는 VRAM 부족으로 동시 8 에서 0.36 req/s 까지
붕괴한다(`W1_concurrency.md`). **T1 단독으로 시나리오 B 를 감당할 수 없다** —
전력비가 싼 것이 아니라 처리량이 모자란 것이다. 이것이 3-티어가 필요한 이유다.

## 6. 정리 — 무엇이 빗나갔고 무엇이 맞았나

| 항목 | 판정 |
|---|---|
| 요청당 토큰 | **빗나갔다.** 1,750 가정 → 13,948 실측 (8배). 축소판 카탈로그로 추정한 탓이다 |
| 프리베이크 총비용 | **빗나갔다.** $0.94 → $5.12 (5.4배) |
| 월 운영비 | **빗나갔다.** $195 → $609 (3.1배). 단, 요청 수는 아직 미검증이다 |
| 캐시가 비용을 줄인다 | **맞았다.** 적중률 40.6 % 로 33.4 % 절감 |
| 캐시 적중률 95 % | **빗나갔다.** 암시적 캐싱에서는 도달 불가. 명시적 캐싱 전제였다 |
| 절대 금액대 | **맞았다.** 5배 틀려도 월 $609 는 단일 월드 운영비로 여전히 작다 |

**오차의 90 % 는 하나의 원인이다 — 프리픽스 크기를 축소판으로 추정했다.**
비용 모델 자체(토큰 × 단가, 캐시 1/10 할인)는 실측과 일치한다.
