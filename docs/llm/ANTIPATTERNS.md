# 안티패턴 — 실수 / 증상 / 확인 / 올바른 방법

`CLAUDE.md` §7 의 확장이다. **증상이 한참 뒤에, 엉뚱한 곳에서 나타나는 것**만 모았다 —
바로 터지는 실수는 빌드가 잡는다.

---

## 마스터데이터

### 1. `code`·`bit` 번호 재배치
- **증상** 프리베이크된 플랜이 전부 다른 아키타입/액션을 가리킨다. 검증은 통과한다.
- **확인** `npc diff` → "전량 무효". `git diff masterdata/*.json` 에서 기존 항목의 번호가 바뀌었나.
- **올바른 방법** 추가는 **맨 뒤에만**. 번호는 `npc next-code <파일>` 이 답한다. 지우지 않는다.

### 2. `duty_hours` 없이 `Guard`·`Patrol` 허용
- **증상** 그 아키타입의 재계획 큐가 포화된다. 인지 스캔이 매 틱 "이탈" 로 읽는다.
- **확인** `npc validate` → **V12**. `npc card archetype <id>` 의 근무 시간 줄에 ✗.
- **올바른 방법** `duty_hours` 를 주거나 그 액션을 뺀다. `OnDuty` 를 세우는 것은 `duty_hours` 뿐이다.

### 3. 생성기를 돌리지 않고 마스터데이터만 고침
- **증상** NPC 가 존재하지 않는 POI 로 걸어간다. 기동도 되고 검증도 통과한다.
- **확인** `npc regen --check` → 비0.
- **올바른 방법** `dotnet run tools/gen_poi_distances.cs` · `gen_npcs.cs`. `derived.lock.json` 도 같이 커밋.

### 4. 생성물을 손으로 편집
- **증상** 다음 재생성에서 조용히 날아간다.
- **확인** 파일 첫 줄에 "생성물이다" 가 있나. `masterdata/prompt/` · `npc_instances.json` ·
  `poi_distances.bin` · `docs/schema/` · `docs/llm/VALIDATION.md`.
- **올바른 방법** 원천을 고치고 생성기를 돌린다.

### 5. POI 정원을 인구보다 적게
- **증상** `gen_npcs` 가 배치 도중 멈추거나 일부 NPC 가 일터를 못 얻는다.
- **확인** `npc validate` → **V10**. `npc card archetype <id>` 의 "집 · 일터" 줄.
- **올바른 방법** POI 를 늘리거나 `capacity` 를 올린다. 인구를 줄이는 것은 세계관 결정이다.

### 6. 가중치 합을 손으로 맞춤
- **증상** 합이 0.9997 이 되어 V5 로 기동 실패. 또는 반올림으로 인구가 5,000 이 안 된다.
- **확인** `npc validate` → **V5**.
- **올바른 방법** `npc scaffold archetype … --weight W` 가 재배분 3안과 잔차까지 맞춰 준다.

### 7. 존 인접을 한쪽만 연결
- **증상** 방향에 따라 도달 불가. 특정 존의 NPC 만 타임아웃이 많다.
- **확인** `npc validate` → **V11**.
- **올바른 방법** `adjacent` 는 **대칭**이어야 한다.

### 8. 문자열 치환 스크립트로 JSON 편집
- **증상** 서식이 깨져 diff 가 파일 전체로 번진다. 리뷰가 불가능해진다.
- **확인** `git diff --stat` 에서 한 줄 고쳤는데 3,000줄이 바뀌었나.
- **올바른 방법** `JsonSurgeon`(F-04) — 무변경 편집은 바이트 동일이다.

## 프롬프트 · LLM

### 9. 플레이어 작성 문자열을 프롬프트에
- **증상** 프롬프트 인젝션. 캐릭터명·채팅·길드명 전부 해당된다.
- **확인** `PromptIsolationTests` 가 서픽스 타입에 `string` 필드가 없음을 리플렉션으로 본다.
- **올바른 방법** 구조화 enum 과 내부 ID 만 싣는다.

### 10. 프리픽스에 동적 값 혼입
- **증상** 프롬프트 캐시 전면 미적중. 비용이 급증하는데 기능은 멀쩡하다.
- **확인** `/metrics` 의 프리픽스 해시 유니크 카운트가 2 이상이면 즉시 경보.
- **올바른 방법** 프리픽스는 기동 시 1회 조립 후 불변. 가변은 전부 서픽스로.

### 11. 프리픽스 무효화 주석을 **뒤에** 붙임
- **증상** 캐시가 안 깨져 측정이 거짓이 된다.
- **확인** 접두 일치다. 무효화 주석은 반드시 프리픽스 **앞**.

### 12. 서픽스에 필드 추가
- **증상** 300 → 800 토큰. prefill 이 3배가 된다.
- **확인** `Suffix_NeverExceeds300Tokens` 테스트.
- **올바른 방법** 새 필드가 정말 필요한지 300토큰 예산부터 본다.

### 13. 강제 디코딩을 믿고 검증 생략
- **증상** 유효 JSON 이 나오는데 어휘 검증은 전부 실패한다(실측: 문법을 지키며 인자를 지어낸다).
- **확인** `V2.UNKNOWN_ARG` 가 쏟아진다.
- **올바른 방법** 4단 검증기를 **항상** 통과시킨다. 제공사별 `strict` 지원이 다르다.

### 14. 검증 실패 시 2회 이상 재시도
- **증상** 성공률은 거의 안 오르고 토큰만 탄다.
- **올바른 방법** **1회만**. 두 번째부터는 폴백이 낫다.

### 15. 일일 캡을 우회하는 코드
- **증상** 예산 경보가 안 뜨는데 청구서가 나온다.
- **올바른 방법** 초과 시 **T2 → T1 강등 → 거절**. 우회 경로를 만들지 않는다.

### 16. 검증 실패분을 조용히 폐기
- **증상** 품질 개선의 원자료가 사라진다. "왜 실패율이 32%인지" 를 알 수 없다.
- **올바른 방법** `planstore/rejected/` 에 실패 코드와 함께 보존한다.

## 틱 루프 · 런타임

### 17. 틱 루프에 LINQ 한 줄
- **증상** Gen0 GC 폭증, p99 초과. 500마리에서는 안 보이고 5,000마리에서 터진다.
- **확인** 부하 회차의 `/metrics` `bytesPerTick`. **`gen0Collections` 로 재지 않는다** —
  그 값은 프로세스 전역이라 대시보드 HTTP·소켓이 전부 든다.
- **올바른 방법** 첨자 순회. 계기는 `bytesPerTick` 하나다.

### 18. 틱 루프에서 LLM 호출
- **증상** 틱이 몇 초씩 밀린다.
- **확인** `Npc.Runtime` 이 `Npc.Llm` 을 참조하나 — `ArchitectureTests` 가 막는다.
- **올바른 방법** 재계획은 별도 `BackgroundService`. 결과는 `Volatile.Write` 로 넘긴다.

### 19. 워커가 틱 루프 상태를 직접 수정
- **증상** 데이터 레이스. 리플레이가 일치하지 않는다.
- **올바른 방법** `PendingPlanId` 에 `Volatile.Write` 만. 반영은 스텝 경계에서.

### 20. 재계획 큐에 같은 NPC 중복 삽입
- **증상** 큐가 즉시 포화되고 다른 NPC 가 굶는다.
- **올바른 방법** `_heapPos` 로 중복을 검출해 점수만 갱신한다.

### 21. `Dictionary` 순회에 의존
- **증상** 리플레이가 실행마다 다르다. 재현이 안 된다.
- **올바른 방법** 정렬된 배열.

### 22. 스텝 중간에 플랜 스왑
- **증상** `CorrelationId` 가 꼬여 응답이 엉뚱한 스텝에 붙는다.
- **올바른 방법** 스텝 경계에서만. 인터럽트는 예외지만 진행 중 명령을 상관 ID 로 무시한다.

### 23. 소켓 경로에서 리플레이 일치를 기대
- **증상** "결정론이 깨졌다" 고 보고하는데 결함이 아니다.
- **올바른 방법** 리플레이 일치는 루프백의 성질이다. 결정론이 필요하면 `--loopback`.

## 연동 계약

### 24. `IGameServerLink` 에 반환값 있는 메서드 추가
- **증상** 게임서버 왕복을 기다리며 틱이 밀린다.
- **확인** `Contracts_*` 테스트(N1).
- **올바른 방법** 명령은 fire-and-forget. 결과는 **이벤트로만**.

### 25. 패킷에 `string`·`DateTime` 필드
- **확인** `Contracts_*` 테스트(N3·N4).
- **올바른 방법** 강타입 ID 와 `Tick`(long).

### 26. 명령이 도착한다고 가정
- **증상** 응답 이벤트가 안 오면 NPC 가 영원히 그 스텝에 멈춘다.
- **확인** `Npc.Sim --drop-rate` 로 상시 시험한다.
- **올바른 방법** 모든 스텝에 `timeout_s`. 만료되면 로컬에서 `ActionFailed(Timeout)` 을 합성한다.

### 27. 와이어 v1 DTO 수정
- **증상** 배포된 게임서버가 프레임을 못 읽는다.
- **확인** `Wire_LayoutIsFrozen` 테스트.
- **올바른 방법** v1 은 동결이다. 새 필드는 v2 에.

## 운영

### 28. 낡은 파생물로 기동하고 무시
- **증상** 경고는 나왔는데 아무도 안 봤다. 며칠 뒤 "왜 이 NPC 만 이상하지" 가 된다.
- **확인** 기동 로그의 `경고 파생물 …` · `npc regen --check`.
- **올바른 방법** 파이프라인에 `npc regen --check` 를 건다.

### 29. `--bind 0.0.0.0` 을 토큰 없이
- **증상** 관리 API 가 열린다. 킬스위치를 아무나 당긴다.
- **확인** 기동이 거절된다 — 그것이 설계다.
- **올바른 방법** `NPC_ADMIN_TOKEN` 을 **환경변수로**. 인자는 `ps` 에 보이고 파일은 이미지에 굽힌다.

### 30. `manifest.json` 에 `DateTime.Now`
- **증상** 같은 입력에 다른 파일이 나와 diff 로 검토할 수 없다.
- **올바른 방법** 시각은 외부에서 인자로 주입한다.
