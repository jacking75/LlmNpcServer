V7폴백 존재 · loop:true폴백 플랜 'fb_shepherd' 이 … 에 없다

D. 되돌리기

무엇을어떻게
실습장 하나./samples/lab.ps1 -Drop <이름>
실습장 전부Remove-Item lab -Recurse -Force — .gitignore 라 흔적이 없다
본체를 고친 실습 (7·9·12장)전용 브랜치에서 한다. revert.ps1 -Yes → git switch main
ArchetypeCount 를 되돌렸는데 이상하다다시 빌드한다. 파일은 40인데 바이너리가 41이면 가장 찾기 어렵다
생성물 (npc_instances.json · poi_distances.bin)손으로 못 되돌린다. git restore masterdata
플랜 스토어planstore/plans/ 는 지워도 된다 — 재생성 가능.
pinned/ 는 지우지 않는다
측정 원자료를 덮어썼다git restore docs/measurements
되돌리기 전에 확인 git restore 는 그 경로의 모든 변경을 날린다. 실습 중에 다른 것도 고쳤다면 그것까지 사라진다. 전용 브랜치에서 실습하라고 반복하는 이유다.
