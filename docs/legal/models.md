# 모델 약관

> **이 표는 조사 시점의 기록이지 법무 검토 결과가 아니다.**
> 상용 투입 전에 **각 제공사의 현행 약관을 다시 확인**한다 — 약관은 자주 바뀐다.

## 우리가 쓰는 모델

`appsettings.Llm.json` 이 사실의 출처다. 아래는 그 목록에 대한 조사 항목이다.

| 엔진 | 모델 | 어디 | 확인해야 할 것 |
|---|---|---|---|
| `llamacpp-qwen3-8b` | Qwen3 8B | 로컬 (GGUF) | 가중치 라이선스 · 상용 이용 · 재배포 |
| `llamacpp-gemma3-4b` | Gemma 3 4B | 로컬 (GGUF) | Gemma 이용약관의 사용 제한 조항 |
| `dotllm-qwen2.5-7b` | Qwen2.5 7B | 로컬 (GGUF) | 위와 같음 |
| `dotllm-phi4-mini` | Phi-4 mini | 로컬 (GGUF) | MS 모델 라이선스 |
| `openrouter-*` | 여러 제공사 | 외부 API | OpenRouter 약관 + **원 제공사 약관** 이중 적용 |
| `gemini-*` | Gemini | 외부 API | 상용 이용 · 데이터 학습 이용 여부 |
| `poe-*` | Poe 경유 | 외부 API | 경유 서비스 약관 |

## 조항별로 확인할 것

| 조항 | 왜 중요한가 | 상태 |
|---|---|---|
| **상용 이용 허용** | 게임 서비스에 쓴다 | **미확인** |
| **출력물 권리** | 생성된 플랜 2,880개가 우리 자산인가 | **미확인** |
| **데이터 보존·학습 이용** | 프롬프트에 세계관이 들어간다 — 학습에 쓰이면 유출이다 | **미확인** |
| **가중치 재배포** | 이미지에 GGUF 를 넣을 것인가 (지금은 안 넣는다) | 해당 없음 |
| **사용 제한(acceptable use)** | 게임 콘텐츠 생성이 금지 용도에 들어가는가 | **미확인** |
| **레이트·쿼터** | 실측 외부 동시성 24까지 429 0회. 32·64 는 **미측정** | 부분 |

## 우리가 이미 한 것

- **플레이어 작성 문자열을 프롬프트에 넣지 않는다** (`CLAUDE.md` §2.5).
  캐릭터명·채팅·길드명이 제공사로 나가지 않는다 — 개인정보 노출면이 그만큼 좁다.
- 프롬프트에 실리는 것은 **마스터데이터에서 온 구조화 enum 과 내부 ID** 뿐이다.
  세계관 설명(`desc`)은 나간다 — **그것이 학습에 쓰이는지가 위 표의 세 번째 줄이다.**
- `IChatClient` 추상화라 제공사를 바꾸는 데 코드 변경이 없다.

## 판정

| 항목 | 상태 |
