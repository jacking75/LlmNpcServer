# 위협 모델

> 자산 → 경계 → 위협 → 대응 → **잔여 위험** 순이다.
> **잔여 위험 절을 지우지 않는다** — 없는 것을 채우면 판단이 거짓이 된다.

## 1. 자산

| 자산 | 왜 지키나 | 어디 |
|---|---|---|
| **명령 스트림** | 위조되면 NPC 가 공격·이동을 임의로 한다 | 링크 (TCP) |
| **마스터데이터** | 세계관 자산. 유출되면 콘텐츠가 새고, 변조되면 기동이 깨진다 | `masterdata/` |
| **프리베이크 플랜** | 실질 산출물. 2,880건 ≈ $5.12 의 결과물 | `planstore/` |
| **API 키** | 도난되면 비용이 무한히 나간다 | 환경변수 |
| **링크 시크릿** | 도난되면 게임서버를 사칭할 수 있다 | 환경변수 |
| **관리 토큰** | 킬스위치·스냅샷을 아무나 당긴다 | 환경변수 |
| **플레이어 id** | 개인정보. 로그·스냅샷에 남는다 | `docs/security/privacy.md` |

## 2. 신뢰 경계

```
[게임서버] ──TCP(링크)──> [NPC 서버] ──HTTP──> [외부 LLM 제공사]
                              │                      ▲
                              ├──HTTP──> [로컬 추론 프로세스]
                              │
                         [관리 API]  <── 운영자
                              │
                         [디스크: masterdata · planstore · state]
```

| 경계 | 신뢰하나 | 방어 |
|---|---|---|
| 링크 (게임서버 ↔ NPC) | **아니오** | HMAC-SHA256 상호 인증 · 논스 재사용 캐시 · TLS/mTLS · 구조 해시 완전 일치 |
| 관리 API | **아니오** | 토큰 · 분당 실패 5회 제한 · 감사 로그 · `--bind 0.0.0.0` 은 토큰 없으면 기동 거절 |
| 외부 LLM 제공사 | **아니오** | 출력을 4단 검증기에 통과시킨다 · 플레이어 문자열을 보내지 않는다 |
| 로컬 추론 프로세스 | 부분 | 같은 호스트. 출력은 역시 검증기를 지난다 |
| 디스크 | 부분 | 스냅샷 CRC32 · 마스터데이터 해시 검사 |

## 3. 위협 · 대응

| # | 위협 | 대응 | 상태 |
|---|---|---|---|
| T1 | **위조 이벤트 주입** — 가짜 게임서버가 붙어 상태를 조작 | HMAC 상호 인증 + 논스 · `FixedTimeEquals` · 구조 해시 일치 요구 | **구현됨** (A-06) |
| T2 | **명령 스트림 관측** — 평문으로 세계 상태가 새어 나간다 | TLS/mTLS. 인증서 검증 무력화 옵션을 **두지 않았다** | **구현됨** (A-06) |
| T3 | **재전송(replay)** | 논스 캐시 256 · 세션 에포크 | **구현됨** |
| T4 | **관리 API 남용** — 킬스위치를 당겨 서비스를 멈춘다 | 토큰 + 레이트 리밋 + 감사 로그 | **구현됨** (A-11) |
| T5 | **프롬프트 인젝션** — 플레이어가 쓴 문자열로 플랜을 조종 | **플레이어 문자열을 프롬프트에 넣지 않는다.** 리플렉션 테스트가 강제 | **구현됨** (C-06) |
| T6 | **비용 고갈** — LLM 호출을 유발해 청구서를 태운다 | 일일 토큰 하드 캡 · 벽시계 USD 캡 · 서브 쿼터 · 우회 경로 없음 | **구현됨** (C-02·C-07) |
| T7 | **LLM 출력이 악의적 플랜** | 4단 검증기. 강제 디코딩을 신뢰하지 않는다 | **구현됨** |
| T8 | **`reasoning` 필드로 내용 유출** | 제어문자·URL·이메일 제거 · 금칙어면 통째로 비운다 | **구현됨** (C-06) |
| T9 | **시크릿 유출** — 인자·이미지·로그 | 환경변수로만. 인자는 `ps` 에 보이고 파일은 이미지에 굽힌다 | **구현됨** (A-06) |
| T10 | **낡은 파생물로 잘못된 세계** | `derived.lock.json` · 기동 경고 · `regen --check` | **구현됨** (F-04) |
| T11 | **의존성 취약점** | `dotnet list package --vulnerable` · 중앙 패키지 관리 | **구현됨** (아래 실측) |
| T12 | **공급망 — 모델 가중치 변조** | 모델 파일 해시 고정 | **미구현** (C-08) |
| T13 | **로컬 추론 프로세스 장악** | 감독·헬스·재시작 | **미구현** (C-08) |
| T14 | **DoS — 링크 연결 폭주** | — | **미구현** |
| T15 | **스냅샷 변조** | CRC32 는 무결성이지 **인증이 아니다** — 서명이 없다 | **미구현** |

## 5. 잔여 위험 — **지우지 않는다**

| 위험 | 왜 남아 있나 | 어떻게 없애나 |
|---|---|---|
| **모델 가중치 변조** (T12) | 해시 고정이 없다 | C-08 |
| **로컬 추론 프로세스 장악** (T13) | 감독이 없다 | C-08 |
| **링크 DoS** (T14) | 연결 수·속도 제한이 없다 | 앞단(LB·방화벽)에서 막거나 신규 태스크 |
| **스냅샷 변조** (T15) | CRC32 는 인증이 아니다 | 서명 또는 디스크 접근 통제 |
| **침투 시험 미실시** | 사람과 시간이 필요하다 | 외부 검토 |
| **이미지·시크릿 스캔 미실시** | 파이프라인에 붙이지 않았다 | 아래 §6 |
| **법무 미확인** | dotLLM GPLv3 · 모델 약관 | `docs/legal/` |
| **무중단 시크릿 회전 없음** | 세 비밀 모두 기동 시 1회 읽는다 | `docs/security/secrets.md` |
